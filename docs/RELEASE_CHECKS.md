# 0.6.3 公开预发布检查

2026-10-20。兼容依据仍为 Windows DSH Desktop 0.2.1-rc.2。仅有限功能合并与回归检查，不是完整安全审计，不代表多平台、多版本或真实 DSH 最终验收。

## 合并范围

- 新增启动页人物、一次入场动画、偏好开关、输入框避让与居中气泡；Claude 修订为白色系带粗跟短靴。
- 按文件合并，保留公开版 DSH_HOME 安装路径、作品消息校验、全角 CSV 公式转义等修复。
- 人物只使用内置 PNG data URL，无图片网络请求；没有新增消息发送、聊天读取、作品网络或文件权限。文字使用 textContent。监听器、观察器与原生布局标记在关闭/卸载时释放。
- 明确清单仅纳入三张生成 PNG，排除原参考截图、用户对话、账号、profile、work、backups、原应用资源及无关工作文件。
- 素材许可与代码分开，维护者确认已获改绘版公开分发授权；详见 WELCOME_ASSETS.md。

## 本轮验证

- Windows / Node 24.19.0：95 项 Node 测试通过，包括保留的 3 项公开安全回归及新增 4 项人物偏好/布局/画笔开关检查。
- PowerShell 7：19 项隔离安装断言通过；模拟执行器，未调用真实 profile 安装或卸载。
- 独立 Chrome：50 项启动页检查通过，覆盖三风格×明暗、气泡两行居中与留白、出现时机、草稿/焦点、独立与全局开关、窗口/侧栏、错误恢复、减少动画与清理。
- 14 项归档检查通过：SHA256、明确文件清单、安全路径、干净源码重建一致、解压后 95 项 Node 测试与 19 项隔离安装断言、演示重建及源码独立重打包字节一致。

人物浏览器工具：scripts/verify-welcome.cjs，需 Playwright 与 Chromium，可用 NODE_PATH / BROWSER_EXECUTABLE 指向已有安装。所有样例为通用测试内容，不连接 DSH 或模型。

仍待用户验收：真实 DSH 最终视觉、所有缩放与插件组合、完整启停/卸载重装、长会话表现、其他平台和版本。既有模型选择差异、作品资源上限与数据淘汰限制仍适用。历史图形检查见 docs/0.6.1.md 与历史报告，其数字不作为本轮已执行结果。
