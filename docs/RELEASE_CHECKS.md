# 0.6.5 安装器维护更新检查

2026-10-20。新增自定义应用目录、注册表发现和安装前路径/版本检查，修复 Windows PowerShell 5.1 对 UTF-8 无 BOM 配置中的中文链接误判。兼容依据仍为 Windows DSH Desktop 0.2.1-rc.2。不是完整安全审计。

- 95 项 Node 测试通过；Windows PowerShell 5.1 和 PowerShell 7 各 54 项隔离安装断言通过，包括公共入口参数、自定义路径与可执行文件路径、特殊字符、多安装冲突、失败前无配置修改、版本和 UTF-8 无 BOM。
- 使用已安装的真实 DSH 0.2.1-rc.2 CLI，在工作区临时 profile 中分别完成默认路径与自定义路径别名的安装、自检、卸载；真实 profile 的 SHA256 保持不变。应用通过 junction 别名访问，没有复制到 D 盘，不扩大为真实 D 盘/其他 DSH 版本已完整验证。
- 15 项归档检查通过，包括校验值、明确文件清单、干净源码重建一致、解压后 95 项 Node 测试、两个 PowerShell 版本的安装断言、演示重建与独立重打包一致。
- 实际工作证据留在 work/native-installer-* 与 work/qa-stage6，不打包临时 profile、目录别名、原应用资源或日志。
- 本轮不操作真实 DSH 会话，不宣称最终视觉、其他平台、多版本或真实用户完整卸载重装已验收。仓库简介和原有功能介绍保持原样。

## 同步内容与边界

- 合并主动可视化指南、紧凑数字折线图、SVG 自动适配、滚轮/按钮/键盘缩放与双击恢复；详见 [0.6.1](0.6.1.md)。
- 只迁移相关源码和回归工具，保留公开版既有的 DSH_HOME 安装路径、作品消息字段/类型/大小校验与全角 CSV 公式前缀修复。没有整体覆盖公开仓库。
- 显示缩放只作用于已有内置 SVG，不修改 viewBox 或数据，不跨 iframe 注入代码。导出移除临时宽高样式；范围筛选、参数重绘仍沿用现有模型与受限表达式。
- 几何尺寸来自插件受约束的渲染器，自动尺寸和倍率有界。观察器仅覆盖自有组件；替换、关闭与卸载清理监听器/观察器。没有新增运行依赖、网络能力、存储键、字体或第三方素材。
- 明确清单打包，排除 work、backups、profile、聊天、原应用资源与本次未批准截图。既有六张已批准图片保留，并说明来自 0.6.0 展示。
