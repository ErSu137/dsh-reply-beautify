# 0.6.0 公开预发布检查

2026-10-19；有限代码检查与回归，**不是完整安全审计**。本次独立整理在干净发布目录，未更改用户现有 DSH 对话、未操作 DSH 界面，也未在真实 profile 卸载重装。兼容依据仍是 Windows DSH Desktop 0.2.1-rc.2；manifest 限定该版本，不能据此宣称已完成全平台/多版本测试。

## 实际实现与检查

Host 入口只注册静态指南工具和自有系统提示段；客户端通过原生模块加载器、画笔扩展位、隐藏会话标记和右侧栏接口工作。内容控制器只处理助手正式回复，保留原生节点并提供原文回退。解析器显式限制组件大小/数量/类型；DOM/SVG 渲染器使用固定元素与文本节点。普通表达式采用受限算术 AST；状态保存在本机浏览器存储；作品使用双层不透明来源 iframe、CSP 和状态消息桥。

逐项检查了：HTML/SVG文本与URL、公式过滤与原生渲染边界、表达式、CSV、iframe sandbox/CSP、postMessage来源/通道/值类型、状态容量与损坏、计时器/监听器清理、超大输入与原文恢复，以及安装参数/备份/错误处理、构建和归档清单。

| 发现 | 修复与证据 |
| --- | --- |
| 自定义 DSH_HOME 下 CLI 与备份/检查路径不同 | 安装器统一遵循 DSH_HOME；新增默认/自定义路径断言 |
| 作品转发原始消息，错误字段类型未限制 | 仅转发约定字段；对象状态及24000字符限制；错误仅字符串并截断300字符；Host忽略非法错误；新增协议回归 |
| CSV漏掉全角公式前缀 | 标题与数据同样转义＝＋－＠，保留已有ASCII/控制字符处理；新增回归 |

普通组件未发现直接将模型HTML/SVG插入主页面的路径；普通表达式未发现任意JS执行入口。这只描述本轮检查结果，不是不存在其他漏洞的保证。来源链接仍由用户自行判断，模型分数、答案和引用不会被插件核实。
