# 第5阶段验收：复杂作品与预览空间

作品功能于0.5.0引入，已通过用户阶段验收，当前交付0.6.0沿用本指南。视觉与实机检查由用户执行；本次未控制电脑、浏览器或现有DSH对话。最终集成检查见第六阶段验收指南。

## 准备

1. 完全退出DSH，再启动，让新增作品指南和原生右侧栏模块加载。无需重装本地链接。
2. 左下画笔确认当前交付版本0.6.0并开启美化，保留自己喜欢的字号和预设。
3. 新建“第5阶段作品验收”对话。不要在原有工作/学习会话试验。

## 自然语言生成复杂作品

直接发送下面提示词，没有指定插件格式：

> 帮我做一个可以反复使用的项目交付模拟器，放在回复中操作。分“总览、工作量、风险”三个视图：可以添加和删除任务，修改每项预计工时，勾选是否纳入计划；能调整参与人数、每人每天有效工时和目标天数。总览联动显示总工作量、预计完成天数和能否按期，并用可视化展示工时分配。明确写出计算规则，不把估算当实测数据。离开后重新打开能保留我的输入；深浅色下都清楚，窄窗口也能操作。不联网、不读写文件、不执行命令。

若模型只给文字或已有结构化组件，并不意味着预览坏了；模型仍有形式选择权。可补充“这次请做成有三个视图、可添加任务的完整交互小工具”，或用[固定样例](第五阶段-固定样例.md)排除模型生成差异。

## 逐项检查

| 检查 | 操作与预期 |
| --- | --- |
| 回复内预览 | 点击“运行预览”；工具应在回复卡片中打开；操作只改变作品，输入框仍能正常使用 |
| 侧栏 | 点击“在侧栏打开”；应打开DSH原生右侧栏的“作品空间”，列出当前对话的作品；点击运行后可并排查看 |
| 全屏 | 点击“全屏预览”，再运行；内容有足够空间，关闭按钮或Escape能退出，原对话位置保持 |
| 停止与原文 | 点击“停止预览”或外层“查看原文”；页面运行撤下，原始回复仍可复制 |
| 连续修改 | 在同一对话发下方修改提示词；新回复应更新同一作品并增加模型版本，版本菜单能切回旧版 |
| 本机修改 | 点“编辑源码”，改一处标题文字，应用为新版本；能看到本机版本，并切回模型原版；模型原文不变 |
| 状态恢复 | 改输入，停止再运行、关闭再开侧栏，输入应恢复；再完全重启DSH测试。仅对已接入状态API的作品成立 |
| 会话隔离 | 新建另一对话，生成同样的工具；两边输入应独立，不继承原对话状态 |
| 风格 | 运行中切换默认/GPT/Claude和明暗；使用预设变量的作品应适配，已保存输入不丢失 |
| 总开关 | 关闭美化，回复恢复原文，运行页面撤下，全屏窗口关闭；重新开启可以再次预览 |

连续修改提示词：

> 在刚才这个工具上继续修改，保留已有输入：增加每人每日成本，显示总成本估算；风险视图用三种不同颜色区分按期、临界和超期。保持同一件作品，保留原有视图和操作。

固定样例校对：初始优先级5×5=25，输入任务名，把重要性改成8，应显示40；停止再运行及重启后仍应为任务名和40。若固定样例能恢复，而自由生成工具不能恢复，应检查模型页面是否正确使用状态API。

## 反馈最有用的信息

注明“回复内/侧栏/全屏”、预设和明暗，发生问题的动作，以及作品状态栏文字。视觉问题可截图；如果只出现原文，可查看JSON是否完整、id是否稳定、version是否递增。无需发送已有聊天历史。
