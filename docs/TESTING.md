# 下载后验收与周末测试

仅新建专用测试对话；不要公开私人聊天、账号、profile 备份。最终视觉验收由用户执行，代理本轮不控制 DSH。

## 下载到安装

1. 下载 Release 命名 zip 与 SHA256SUMS，运行 Get-FileHash 比对。
2. 解压到长期保留目录，进入有 install.ps1 的内层目录，读[安装说明](安装更新与恢复.md)。
3. DSH 启动过一次后完全退出，执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./install.ps1 -Check`，核对 Executable、ProfileDirectory、PluginRoot。
4. 执行安装再自检：Linked、BundleRegistered 应为 true，ProfileDirectory 跟随 DSH_HOME。保留备份位置。
5. 重启确认画笔 0.6.1，记录 Windows/DSH 版本、预设、明暗、宽度、缩放。
