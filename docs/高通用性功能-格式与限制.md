# 高通用性功能：格式与限制

插件0.4.0。所有新组件使用 `dsh-ui` 围栏，`type` 决定类型，也支持对应 `dsh-table` 等标签。DSH隐藏语言时识别明确类型，普通json代码块不改。单块源内容最多40000字符。数据、评分、引用和公式来自模型回复；插件不联网补造。

## 交互表格（table）

Interactive table: columns 1–12 {id,label,type:text|number,editable?:boolean,expression?:string}; rows 0–200 {id,values:{columnId:value}}. Supply every raw cell; formula columns are read-only number columns and may reference only raw numeric column IDs, no formula chains. Search, header sorting, column visibility and CSV export are built in. Optional chart {type:bar|line,category:columnId,series:[numericColumnId]} uses the same edited/filtered rows; at most24 rows are graphed, otherwise asks to filter. Do not invent data.
Common: emit complete fenced dsh-ui JSON with type table, title and optional description. IDs letter-led ASCII letters/digits/underscore/hyphen, unique within the specified scope; numeric expression IDs cannot contain hyphens or reserved constants/function names. Numeric values finite abs<=1e12; texts are literal. All interactions are local; copy and send results explicitly to continue. Original source always available.
Example (sample data/assumptions, not factual claims):
```dsh-ui
{"type":"table","title":"数量与成本","columns":[{"id":"item","label":"项目","type":"text"},{"id":"qty","label":"数量","type":"number","editable":true},{"id":"price","label":"单价","type":"number","editable":true},{"id":"total","label":"总价","type":"number","expression":"qty*price"}],"rows":[{"id":"a","values":{"item":"甲","qty":2,"price":30}},{"id":"b","values":{"item":"乙","qty":3,"price":20}}],"chart":{"type":"bar","category":"item","series":["total"]}}
```

## 计算器（calculator）

Calculator/unit conversion: fields 1–12 {id,label,min,max,value,step?,unit?}, results 1–12 {label,expression,unit?}. Input min<max, initial within range. Use explicit reliable conversion formulas; no network rates. Same documented arithmetic functions as explorer. Results update locally and invalid inputs suppress calculated outputs.

Numeric values finite abs<=1e12; texts are literal. All interactions are local; copy and send results explicitly to continue. Original source always available.

## 方案比较（compare）

Decision comparison: criteria 1–10 {id,label,min,max,weight:0..10,prefer:higher|lower}, options 2–10 {id,label,summary?,pros?:[text],cons?:[text],scores:{criterionId:number}}. Every option must supply every score within the criterion range. Scores are normalized to0..1, inverted for lower, weighted then scaled to100. All-zero weights give no result. Show assumptions and source of scores/weights; never present the ranking as an objective fact. Weight controls and cards/matrix are built in.
Common: emit complete fenced dsh-ui JSON with type compare, title and optional description. IDs letter-led ASCII letters/digits/underscore/hyphen, unique within the specified scope; numeric expression IDs cannot contain hyphens or reserved constants/function names. Numeric values finite abs<=1e12; texts are literal. All interactions are local; copy and send results explicitly to continue. Original source always available.

## 图表与参数探索

`dsh-chart`支持bar、line、stacked、pie、donut，最多24标签、4系列。pie/donut只允许一组非负且总和大于零的数据。系列开关、起止范围、坐标图拖选、鼠标/键盘读数、表图高亮、当前SVG导出均在本地运行；不修改原始数据。堆叠图分别累计正负值。图表缩放是分类范围缩放，不是任意连续坐标平移。

`dsh-explorer`沿用第四阶段格式，额外提供最多3个命名参数快照、载入/移除及比较。一次叠加比较选定的一条曲线，当前加快照最多4条，使用相同坐标轴；另列各项指标。快照仅保存参数，不复制采样数组。SVG工具栏导出主图，快照结果可用复制获取。

## 本地边界

所有操作默认留在本机，不自动发消息、修改文件或创建外部任务/日历事件。数据与偏好最多保留80块、约280000字符，旧记录可能淘汰；本地存储失败时界面提示临时状态。来源卡片仅在用户点击链接时打开外部页面。思维导图与排期等使用DOM/CSS绘制，并非所有组件都可导出SVG；图表与原流程图可以导出SVG，表格/报告可导出CSV。

0.4阶段未加入低通用性专用组件（散点/直方/箱线/热力/误差图、专项系统图、练习题扩展、图片热点、几何、地图等）。0.5阶段另增加了通用隔离作品页面，复杂小应用可按作品格式实现，见第五阶段作品格式说明；这不代表已有上述各类专用组件。
