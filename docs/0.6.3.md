# 0.6.3 · 新对话启动页人物与问候气泡

合并本地 0.6.2 的启动页人物功能及 0.6.3 的鞋子、气泡修订，保留公开版安全与安装修复。兼容依据为 Windows DSH Desktop 0.2.1-rc.2，仍为预发布。

- 默认、ChatGPT、Claude 三种排版风格分别对应鲸鱼女仆、银白龙娘、橙发学者。人物仅出现在主新对话启动页；普通聊天与加载页不显示。
- 空间充足时，默认形象约占可用高度 1/3，GPT/Claude 约 2/3，脚部离底边约 24 CSS 像素。Claude 穿白色系带粗跟短靴。
- 气泡文字为两行居中的“你好，请问 / 可以怎么帮你”，深浅主题分别配色。
- 启用美化/人物、在启动页切换风格、从已有对话进入新会话时播放一次淡入；遵守系统减少动态效果设置。输入、调字号和缩放窗口不反复播放。
- 画笔新增“启动页卡通形象”独立开关，默认开启并保存到本机。切换预设与恢复当前样式不会重置该开关；美化总开关也控制人物。
- 输入框保留原节点与草稿，必要时为人物预留右侧空间；窄窗口缩小或暂时隐藏人物，避免遮住输入框。图片失败、关闭或停用时恢复布局并释放监听器。
- 图片内置于本地客户端，不从远端加载；不调用模型、发送消息或读取私人聊天。人物素材及内嵌图片字节不适用代码 MIT，见 [素材说明](WELCOME_ASSETS.md)。

## 验收

完整退出 DSH（包括托盘）后，按 README 更新并重启，画笔应显示 0.6.3。在专用测试对话中检查三种风格、深浅主题、独立开关与重启保存、从已有对话进入新会话、减少动画、窄窗口及右侧栏。确认人物/气泡不挡输入，已有草稿保持，Claude 鞋与问候文字显示正确。

自动测试使用通用独立样例，不代替真实 DSH 的最终视觉、多版本、多平台、长会话或卸载重装验收。历史图表缩放与可视化指引仍见 [0.6.1](0.6.1.md)。
