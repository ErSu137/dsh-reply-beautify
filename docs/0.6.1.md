# 0.6.1 · 图形适配与缩放

公开预发布，兼容依据仍为 **Windows DSH Desktop 0.2.1-rc.2**。最终 DSH 视觉、真实启停/重装、长会话和其他版本/平台验收仍待完成。

## 主动选择可视化

模型指南要求解释趋势、曲线、比较、结构和流程时先判断图示是否有帮助；适合且能够准确表达时，在同一回复优先使用支持的组件，避免默认输出手画 ASCII 图。用户无需知道格式名，明确要求纯文本时仍尊重要求。

有可靠数值或明确推导规则时使用数据图表，有可靠公式时使用参数曲线。只有概念关系而没有数值坐标时，可用标明“示意／非测量／非比例”的隔离作品，避免虚构刻度。作品仍需点击“运行预览”，隔离边界不变。

这提高了模型使用组件的优先级，**不能保证每次都遵循**。未做本轮真实模型生成成功率测试。旧回复不会重新生成；缺少可靠数值坐标的旧 ASCII 曲线不会被猜测转换成数据图。

## 适配与缩放

- 内置 SVG 流程图、图表、参数曲线、表格和报告中的联动图保持比例。宽高比在 **1:3～5:1** 时默认适配可用宽度和高度，完整展示而不裁切数据；极端比例保留原尺寸和滚动能力，避免缩成难读的细条。单边最大 8192 CSS 像素。
- 短数字分类的折线图使用更紧凑的画布，保留全部分类和数据点。
- 鼠标停在图上，滚轮向上放大、向下缩小。图外滚轮继续滚动页面；Ctrl／Command 加滚轮留给浏览器。
- “−／＋／自动”可调整显示，双击图形恢复自动尺寸。聚焦图形区域后可按 +、-、0。放大后在图形区域滚动查看。
- 倍率相对于自动尺寸约为 25%～400%，受尺寸上限限制。数据筛选与显示倍率独立：“恢复全图”恢复数据范围，“自动”恢复显示尺寸。
- 导出 SVG 使用原始几何尺寸和当前选中的数据，不受临时显示倍率影响。组件重绘、重新打开或重启时恢复自动尺寸；倍率不写入持久存储。
- 替换或关闭图形时清理监听器和观察器，保留原文与原有状态。普通照片、公式、HTML 表格/排期/看板和隔离作品内部不适用宿主 SVG 缩放，宿主不跨 iframe 注入代码。

## 更新与验收

按[安装、更新与恢复](安装更新与恢复.md)保留旧目录，新版解压到长期目录，完全退出 DSH 后安装并重启。画笔应显示 **0.6.1**；新建专用测试对话以加载新指南。

1. 打开较宽图表，确认默认能看到最后一个点；缩窄窗口应重新适配，原文和完整数据仍在。
2. 图上滚轮缩放，再双击或点“自动”。图外滚轮应继续滚动对话。改变起点/终点后仍可缩放，“恢复全图”恢复全部数据。
3. 用自然语言测试：“解释预算与实际的差异：甲预算12实际10，乙预算18实际20，丙预算9实际8，单位小时。让我直观看出哪个超支。”记录模型是否主动给出准确图表。
4. 测试无测量值的概念示意，确认有示意标识且无虚构数值。若仍输出 ASCII，记录通用样例；用固定格式区分模型选择和解析问题。
5. 极长横向流程图应保留滚动并能缩放；关闭画笔恢复原文，重新打开不丢失既有偏好。

检查范围见[发布报告](RELEASE_CHECKS.md)。运行 `node scripts/verify-diagram-viewport.cjs` 需 Playwright 和 Chromium；`BROWSER_EXECUTABLE` 可指定已有浏览器，`NODE_PATH` 可指向已有 Playwright 安装。仅构造独立通用页面，不打开 DSH 或连接模型。

## English

Version 0.6.1 strengthens proactive visual guidance without inventing data or guaranteeing model compliance. Built-in SVG charts and flows fit ordinary aspect ratios; extreme diagrams remain scrollable. Hover and use the mouse wheel to zoom, use the buttons, or double-click to reset. Exports retain their original geometry. Rebuilt plots reset display zoom. Artifacts remain isolated and require Run Preview; host zoom does not cross iframe boundaries. This is still a Windows Desktop 0.2.1-rc.2 preview, with real DSH acceptance pending.
