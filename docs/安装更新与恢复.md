# 安装、更新与恢复 · 0.6.5 预发布

兼容依据：Windows DSH Desktop 0.2.1-rc.2。支持默认和自定义应用目录，安装、自检和卸载使用同一套路径解析。其他平台和版本未验证。最新 master 文档不等于本轮旧版接口已实测。

## 下载与安装

从本仓库 v0.6.5 Release 下载命名 zip 和 SHA256SUMS，用 `Get-FileHash -Algorithm SHA256` 比对后解压到长期可写目录，例如 `D:/Plugins/dsh-reply-beautify`。进入含 package.json、lib/client.js、tools/desktop-cli.mjs 和 install.ps1 的内层目录。不要在压缩包中运行。

先启动 DSH 一次初始化 desktop profile，再从“应用 → 退出”完全退出。在插件目录 PowerShell 执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./install.ps1 -Check
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./install.ps1
```

重启 DSH，画笔应显示 0.6.5。安装器使用安装内官方 CLI 与 pnpm，添加绝对路径 link: 并使用 --offline --ignore-scripts；不下载依赖，不改应用文件。检测到运行进程会拒绝变更。插件从解压目录持续加载，请勿移动或删除。

### DSH 安装在 D 盘或其他目录

不需要编辑脚本。以 `D:\DeepSeek Harness` 为例，在插件目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Check -Installation 'D:\DeepSeek Harness'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Installation 'D:\DeepSeek Harness'
# 完全退出 DSH 后，如需卸载：
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Uninstall -Installation 'D:\DeepSeek Harness'
```

`-Installation` 也接受完整的 `DeepSeek Harness.exe` 路径。始终指向应用目录或主程序，不是插件目录，也不是 profile。路径包含空格时保留引号。显式路径无效时直接报错，不会偷偷改用另一份 DSH。

未指定时优先检查 `%LOCALAPPDATA%\Programs\DeepSeek Harness`。默认路径不存在时，读取 Program Files、注册表 App Paths 和卸载记录；只找到一份时使用该位置，找到多份或找不到时输出 `-Installation` 用法，让用户明确选择。不会递归搜索磁盘。

自检输出包含 `Installation`、`Executable`、`DshVersion`、`ExpectedDshVersion`、`VersionCompatible` 和 `VersionError`。安装前核对主程序、资源、内置 pnpm 和 Windows 版本元数据；本版仅支持 `0.2.1-rc.2`。版本未知或不符会在备份及修改 profile 之前拒绝安装。已识别的 DSH 若版本变化，卸载会提示兼容警告后尝试官方移除命令；无法识别的可执行文件不会执行。

默认 profile 为 `%USERPROFILE%/.dsh/profiles/desktop`，若设置 DSH_HOME，改用其下 profiles/desktop。安装、自检、更新、卸载时保持相同路径与环境，不要换 Windows 用户或管理员账号运行。

-Check 只读取文件、链接、bundle 注册和进程，不调用安装 CLI、不创建备份。新装前 Linked/BundleRegistered 为 false 可以正常；安装后应为 true，且 PluginRoot 应是当前解压目录。分享输出前隐去个人路径。

运行 tgz 使用 npm 标准 package/ 结构并含构建产物，供高级用户或标准插件命令使用；普通用户首选命名 zip。官方底层插件命令为 `dsh plugin --profile <name> add <spec>` / `remove <name>`，变更后重启。桌面 profile 需要安装内 CLI 的桌面管理模式，不要用另装的 npm dsh 代替桥接脚本。本次未在真实桌面 profile 重装 tgz，未发布 npm 或自定义市场索引。

官方依据：[CLI 参考](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/cli/reference/README.zh.md#插件管理)、[桌面 CLI 入口](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/desktop/cli/dsh.cmd)。

## 更新、关闭与卸载

更新：保留旧版完整目录，新版解压到新目录；完全退出 DSH 后在新目录运行安装，再重启。回退：退出后在保留的旧目录重新安装。公开包不含开发者私人回退快照，旧版需要自行保留。不要混用不同版本的 client.js、manifest 和 Host 文件。

- 画笔关闭：恢复原文、移除显示与交互视图、停止作品；Host 模型格式指南仍在。
- 原生插件管理停用：框架停用客户端与 Host 能力；必要时完全退出重启后判断。
- 卸载：完全退出后在安装目录执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./install.ps1 -Uninstall`，然后重启。

变更前原样备份 profile 中存在的 package.json、pnpm-lock.yaml、cordis.patch.yml 和 pnpm-workspace.yaml 到插件目录 backups/时间与随机标识。失败会报告错误码和备份位置，并恢复 ELECTRON_RUN_AS_NODE。不会自动覆盖回 profile，以免混合包管理器状态。备份可能含私人配置，请勿上传。停用/卸载不主动删除聊天、工作区、偏好或浏览器记录；配置备份不是完整聊天或状态备份。

本轮在 Windows PowerShell 5.1 和 PowerShell 7 分别通过 54 项隔离断言，并使用真实安装内 CLI、临时 profile 和默认/自定义目录的 junction 别名完成安装、自检、卸载。未修改真实用户 profile 或会话，也未将应用实体移动到 D 盘；朋友的实际 D 盘安装仍应按以上命令验收。开发检查命令见 README。
