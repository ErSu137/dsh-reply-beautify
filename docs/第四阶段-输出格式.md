# 第四阶段：回复内交互与模型指南

插件 0.3.3，适配 DSH Desktop 0.2.1-rc.2。保留第三阶段的静态图示、图表和公式能力。参数探索整体限宽812px并居中，在宽区域将指标纵向放在左侧、曲线放在右侧，窄区域自动上下排列。采样数据独立放在组合下方，不预留指标空列；表头与数据统一左对齐。模型无需指定位置。

## 如何使用

正常表达需求即可。插件通过 DSH 正式 Host 扩展增加一段自己的系统提示，以及只返回格式文档的 `reply_ui_guide` 工具。模型可以自主选择 chart、diagram、quiz、form、explorer，再把完整结构放在正式回复里；读指南本身不会显示组件。模型决定何时使用，不能保证每轮都生成；也可以明确要求“用滑块演示”或“以普通文字回答”。Host 更新后完全退出并重启 DSH，建议在新对话体验。

例如：“比较甲乙丙的预算和实际工时”“给一道单选题检查理解”“用表单整理我的计划偏好”“固定费用30，单价可调，展示数量与总成本的关系”。涉及假设时模型应说明，不擅自补造测量值或公式。

以下结构用于需要精确指定格式的情况。所有标签按纯文字显示；组件内部标签不解析任意 HTML、脚本或 LaTeX。公式正文继续使用原生数学渲染。

## 选择与自测

围栏语言 `dsh-quiz`，`type` 必须是 `quiz`。

```dsh-quiz
{"type":"quiz","title":"核对理解","questions":[{"id":"q1","prompt":"哪个数是偶数？","options":[{"id":"a","label":"3"},{"id":"b","label":"4"}],"correct":["b"],"explanation":"4 可以被 2 整除。"}]}
```

题数1–12，每题选项2–10，ID 唯一且以 ASCII 字母开头。默认单选；多选设置 `multiple:true`，`correct` 给出所有正确选项 ID，按集合完全一致评分。单选答案必须只有一个。`correct` 可省略用于偏好调查，不编造得分。用户填完后主动点击“核对答案”，显示逐题解释和总分；修改选择会撤销旧反馈；可重新作答、复制结果。

答案保存在源 JSON 中，可通过“查看原文”看到；适合自测，不适合保密考试。正确性取决于模型给出的答案。

## 信息表单

围栏语言 `dsh-form`，`type` 为 `form`。

```dsh-form
{"type":"form","title":"整理计划偏好","fields":[{"id":"goal","label":"目标","type":"text","required":true},{"id":"days","label":"天数","type":"number","min":1,"max":30,"step":1,"required":true},{"id":"format","label":"呈现形式","type":"select","required":true,"options":[{"id":"brief","label":"清单"},{"id":"detail","label":"详细计划"}]}]}
```

字段1–12，类型 `text`、`number`、`select`、`multiselect`。文本最多800字；数字必须给出有限的 `min<max`，正 `step` 默认1；选择项2–10。点击“确认填写”检查必填、范围和步长，准备本地摘要；“复制结果”可把摘要粘贴到对话；“清空填写”只清除这块表单的填写。确认不会发送消息或执行外部动作。

## 滑块与曲线联动

围栏语言 `dsh-explorer`，`type` 为 `explorer`。可用于数学、工程参数、数量与成本等明确公式的探索。

```dsh-explorer
{"type":"explorer","title":"数量与成本","description":"示例假设：固定费用30元，成本=单价×数量+固定费用。","unit":"元","parameters":[{"id":"price","label":"单价","unit":"元","min":1,"max":100,"step":1,"value":5}],"x":{"min":0,"max":20,"label":"数量","points":161},"series":[{"name":"总成本","expression":"price*x+30"}],"metrics":[{"label":"10件总价","expression":"price*10+30","unit":"元"}]}
```

参数1–6，曲线1–4，指标0–6。参数包含 `id,label,min,max,step,value`，可选 `unit`；ID 只能由字母开头的 ASCII 字母、数字、下划线组成，不能占用 `x/pi/e` 或函数名。有限范围绝对值≤1e9，初值在范围内；步长必须为正且≥范围/100000。滑块与数值框同步；曲线与指标基于同一组当前参数计算。

`x` 范围有限、绝对值≤1e6，`min<max`；采样40–400点，默认160。纵轴按当前数据自动缩放，变化时请一起看轴刻度。数值采用浮点近似，曲线是采样折线，不能替代精确求解。未定义或非有限采样留下缺口；无有效值时提示，不补造数据。

表达式最多600字符，允许 `+ - * / ^ **`、括号、声明参数、`x`、`pi/e`；不支持隐式乘法。函数：`sin cos tan exp log ln sqrt abs floor ceil round`（1参数），`pow`（2），`min/max`（2–8），`clamp(value,min,max)`。指标只能引用参数，不能引用 `x`。没有 `eval`、属性访问、赋值、HTML、网络调用或自定义脚本。

“恢复参数”恢复源结构初值；“复制当前结果”包含当前参数、指标与所有采样值；“查看采样数据”为节选预览，页面会说明省略。“导出 SVG”获取当前曲线和图例。正态分布可使用 `exp(-0.5*((x-mu)/sigma)^2)/(sigma*sqrt(2*pi))`，确保 `sigma` 始终为正；方差指标为 `sigma^2`。

## 状态、作用范围和回退

组件只增强助手正式回复，用户消息、推理和工具输出不参与。普通 `json` 或程序代码围栏不按交互处理。DSH 隐藏自定义围栏语言时，兼容识别具有明确 `type` 和对应字段的结构；缺失或错误结构保留原文。

交互记录保存在本机 DSH 的 localStorage，键为 `dsh.reply-beautify.interactions.v1`，按会话、消息、块位置和源内容指纹隔离。最多保存80块，约280000字符上限，超限淘汰较旧记录。题目或公式源内容变化会作为新组件。无法可靠确认会话或存储失败时仅保留当前页面状态，界面会明确提示。它不是跨设备同步，也不是永久归档。

选择、滑块、评分、表单确认不会自动进入对话历史，模型看不到这些本地动作。若要继续讨论，请复制结果后自行发送。输入内容作为本地草稿保存，不应把组件当作秘密存储。

画笔总开关控制样式和组件显示，关闭显示原文，再开启恢复可用状态。模型侧已注册的指南仍在；需要连指南一起停用时，通过 DSH 插件管理停用本插件。卸载不主动清除本地偏好和交互记录。后续按用户确认的六阶段计划：第五阶段是复杂作品与预览空间，第六阶段才是兼容和最终交付，各阶段经用户验收后继续。
