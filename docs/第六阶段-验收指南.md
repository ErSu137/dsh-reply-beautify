# 第6阶段最终验收清单

版本0.6.0。由用户负责实机与视觉验收。本次没有代理操作DSH/浏览器、关闭应用或卸载真实插件；现有对话未改动。

## 建议先验收这五项

1. 完全退出并重启DSH，画笔版本0.6.0；原先的字号、预设、行距仍在。只新建专用验收对话。
2. 发下方“流式图表”提示词：图表先出现，复盘继续生成；在生成中切换系列，后文不应重置选择。
3. 切换默认/GPT/Claude与深浅色，缩窄及放宽窗口：控件不重叠，表格/宽图在卡片内滚动，Claude普通强调色仍为橙色，轨迹保留紫/绿/金等语义色；布局与之前验收效果一致。
4. 改参数或表格数据，打开作品预览、修改输入，关闭再打开并重启：应恢复保留范围内的状态。普通图示可复制原文、导出SVG，表格可导出CSV；作品状态恢复仍以正确使用API为前提。
5. 关闭画笔：正式回复恢复原文，作品运行和全屏视图关闭；重新启用后只出现一份增强。再在插件管理中停用/启用，确认入口和模型指南随插件生命周期恢复。

流式图表提示词：

> 先用交互柱状图比较甲乙丙的预算工时12、18、9和实际工时10、20、8，然后继续写约1500字的项目复盘，分五节输出。不联网、不读写文件、不执行命令。

不要在“问候”等已有对话发测试请求。需要数值及组件逐项核对时，沿用[通用功能指南](高通用性功能-验收指南.md)和[作品验收指南](第五阶段-验收指南.md)，无需为这一版重新跑完所有样例。

## 完整检查表

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 历史内容与长会话 | 只读打开长对话，滚动查看旧回复，切换其他对话再回来 | 旧原文不变，图表各一份，输入框仍可用，没有持续增加的卡顿 |
| 流式与多个图表 | 同一回复先图表、后长文，再第二个图表 | 各块完整后独立转换，未完成内容不误隐藏，后文不重建前图 |
| 范围隔离 | 查看用户消息、推理、工具输出和普通代码围栏 | 不转成插件组件；程序源码复制与原生功能可用 |
| 三风格与明暗 | 默认/GPT/Claude×深色/浅色 | 字体、数字、品牌和颜色延续已验收样式；设置可微调并重启保存 |
| 窄屏与缩放 | 窄/中/宽窗口，必要时系统缩放125%/150% | 页面整体不被宽图撑出，工具栏换行整齐，指标/数据表不再错列 |
| 复制与导出 | 复制原文、复制当前结果、导出SVG/CSV | 源码/值正确；SVG能独立打开；CSV的文字不被当作公式执行 |
| 作品生命周期 | 对话内→侧栏→全屏→退出；查看原文/停止预览 | 页面隔离，关闭后停止运行；重新打开恢复API输入，不自动发消息 |
| 重启与升级 | 在组件中修改后完全退出重开 | 保留范围内输入、选定作品版本、字号和预设可恢复 |
| 画笔总开关 | 关闭、重新开启多次 | 原文随关恢复，开启不重复，关闭不留隐藏运行页 |
| 插件启停 | 原生插件管理停用/启用 | 入口、样式、指南随插件变化，无重复注入 |
| 卸载与重装（最后进行） | 完全退出后卸载、启动查看，再退出重装 | 原页面恢复；重装后设置可继续使用，profile不丢失其他插件 |

真实卸载会暂时改变当前环境，因此本轮只做了隔离测试。由你决定是否执行最后一项；没有执行则记为“实机未验证”，不应算作通过。[操作方法与回退](安装更新与恢复.md)。

已知边界：适配接口依据为0.2.1-rc.2；其他版本未做实机验证。普通组件本机最多80条、约280000字符，临时缓存最多160条/560000字符；作品库最多12个作品、每个6版。超限旧记录会淘汰，窗口/设备之间不承诺实时同步。任意复杂Mermaid、循环/时序图仍保留原文；作品iframe不提供CPU无限循环的硬隔离。

若遇到问题，请记下预设、明暗、窗口宽度、具体操作和状态栏文字；视觉问题截图即可，不需要提供原有聊天历史。
